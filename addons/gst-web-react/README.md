# 🎮 gst-web-react

> React + TypeScript версия веб-клиента для Selkies GStreamer WebRTC

Современный веб-клиент для потоковой передачи рабочего стола через WebRTC с полной поддержкой TypeScript и React.

## ✨ Особенности

- 🔧 **Монолитный React компонент** - весь функционал в одном компоненте
- 📘 **TypeScript** - полная типизация для безопасности кода
- 🐛 **Режим отладки** - возможность подключения к серверу на другом хосте (например, 111.111.111.111)
- ⚙️ **Конфигурация через props/URL** - гибкая настройка подключения
- 🎯 **WebRTC с низкой задержкой** - оптимизированная передача видео/аудио
- 🎮 **Поддержка геймпадов** - полная поддержка игровых контроллеров
- ⌨️ **Захват клавиатуры** - захват всех клавиш, включая системные
- 📋 **Clipboard API** - синхронизация буфера обмена
- 📊 **Мониторинг производительности** - отображение FPS, битрейта, задержки

## 📖 Использование

### Через URL параметры (самый простой способ)

Откройте приложение с параметрами:

```
http://localhost:3001/?server=209.250.236.147&port=8080&app=desktop&debug=true
```

**Доступные параметры:**

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `server` | IP/hostname WebRTC сервера (все запросы пойдут на этот сервер) | `window.location.hostname` |
| `port` | Порт сигнального сервера | `window.location.port` или `443`/`80` |
| `app` | Имя приложения | `webrtc` |
| `secure` | Использовать HTTPS/WSS (`true`/`false`) | определяется по протоколу |
| `debug` | Режим отладки (показывает статистику) | `false` |
| `encoder` | Кодек (h264/h265/vp8/vp9/av1) | автоопределение |
| `audio` | Включить аудио | `true` |
| `resizeRemote` | Изменять разрешение на сервере | `true` |
| `scaleLocal` | Локальное масштабирование | `true` |

**Важно:** При указании параметра `server`, клиент будет делать все запросы (включая `/turn`, WebSocket и т.д.) к указанному серверу, а не к `localhost`.

### Через React компонент (для интеграции)

```tsx
import App from './App';

// Базовое использование
<App />

// С переопределением конфигурации
<App config={{
  server: '111.111.111.111',
  port: 8080,
  appName: 'desktop',
  debug: true
}} />
```

### Через файл конфигурации

Отредактируйте `src/config.ts`:

```typescript
export function getConnectionConfig(): ConnectionConfig {
  return {
    server: import.meta.env.VITE_WEBRTC_SERVER || '111.111.111.111',
    port: parseInt(import.meta.env.VITE_WEBRTC_PORT || '8080'),
    appName: import.meta.env.VITE_APP_NAME || 'desktop',
    debug: import.meta.env.VITE_DEBUG === 'true'
  };
}
```

Затем создайте `.env` файл:

```env
VITE_WEBRTC_SERVER=111.111.111.111
VITE_WEBRTC_PORT=8080
VITE_APP_NAME=desktop
VITE_DEBUG=true
```

## ⚙️ Конфигурация

### Параметры подключения

```typescript
interface ConnectionConfig {
  server?: string;       // IP/hostname сервера
  port?: number;         // Порт (443 по умолчанию)
  appName?: string;      // Имя приложения
  encoder?: string;      // Предпочтительный кодек
  debug?: boolean;       // Режим отладки
  audio?: boolean;       // Включить аудио
  resizeRemote?: boolean; // Изменять разрешение на сервере
  scaleLocal?: boolean;   // Локальное масштабирование
}
```

### Режим отладки

При `debug=true` в правом верхнем углу отображается:

- 📊 Битрейт видео/аудио (Mbps)
- 🎬 FPS (кадры в секунду)
- ⏱️ Задержка (latency, ms)
- 💻 Загрузка CPU/GPU (%)
- 🧠 Использование памяти (MB)
- 📐 Разрешение видео
- 🎨 Используемый кодек

### Распространенные проблемы

**Q: Черный экран, нет видео**

A: Проверьте:
- WebRTC сервер запущен и доступен
- Правильные настройки STUN/TURN
- Нет блокировки WebRTC в браузере
- Консоль браузера на наличие ошибок

**Q: Нет звука**

A: Проверьте:
- Параметр `audio=true`
- Аудио не заблокировано браузером
- Кликните на странице (autoplay policy)

**Q: Высокая задержка**

A: Попробуйте:
- Другой кодек (`encoder=h264`)
- Проверьте сетевое соединение
- Убедитесь что TURN сервер настроен

**Q: Не работает клавиатура**

A: Убедитесь что:
- Страница в фокусе (кликните на видео)
- Браузер не блокирует события клавиатуры
- Не активен Pointer Lock (ESC для выхода)
